## Build pipeline
1. `scripts/fetch-github.ts` and `fetch-youtube.ts` run in `prebuild`, write `*.generated.json`. On API failure they fall back to the last committed snapshot in `src/data/snapshots/` so the build never fails on a rate limit.
2. `astro build` reads content collections + generated data.
3. `scripts/og.ts` renders one OG image per page.
4. Cloudflare Pages deploys `dist/`.
5. `nightly.yml` calls the Cloudflare deploy hook so stars and videos stay current.

## DNS cutover (Namecheap → Cloudflare)
See `docs/DNS-CUTOVER.md`. Summary: add site in Cloudflare → it imports existing records → replace nameservers in Namecheap with Cloudflare's two → wait for propagation → add custom domain in Pages → set SSL Full (strict) → redirect `www` → apex.
